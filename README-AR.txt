BuntBewegt — نسخة محسّنة للجوال

ما تم إصلاحه:
- فتح وإغلاق قائمة الجوال من دون تعليق التمرير.
- إمكانية إغلاق القائمة بالضغط خارجها أو على زر الإغلاق.
- تخفيف المؤثرات البصرية الثقيلة وتحسين الأداء على الهواتف.
- تحسين أحجام الصور وإزالة الصور والنسخ الاحتياطية غير المستخدمة.
- تحديث ملفات CSS وJavaScript وتجنب بعض المشاكل على إصدارات Safari الأقدم.

التشغيل:
1. فك ضغط الملف ZIP.
2. ارفع محتويات المجلد كما هي إلى استضافة موقع ثابت (مثل GitHub Pages أو Netlify).
3. افتح index.html على رابط الموقع بعد نشره.
4. إذا ظهرت النسخة القديمة، حدّث الصفحة تحديثاً كاملاً أو امسح ذاكرة التخزين المؤقت.

ملاحظة: هذه صفحات HTML/CSS/JS ثابتة ولا تحتاج إلى خادم برمجي خاص.
